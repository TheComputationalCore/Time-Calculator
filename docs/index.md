# Time Calculator Documentation

Welcome to the official documentation for **Time Calculator**, a Python utility that calculates time by adding a duration to a start time with optional weekday handling.

---

## 🚀 Features
- Supports 12-hour AM/PM format  
- Handles day-of-week input (case-insensitive)  
- Reports day rollovers (next day / N days later)  
- No dependencies  
- Clean and predictable formatting
