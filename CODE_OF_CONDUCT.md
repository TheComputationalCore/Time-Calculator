# Contributor Code of Conduct

This project follows the Contributor Covenant Code of Conduct (v2.1).

## Our Standards
Participants are expected to:
- Be respectful and inclusive
- Accept constructive feedback
- Avoid harassment or discrimination
- Promote a welcoming environment

## Unacceptable Behavior
Examples include:
- Sexualized comments or imagery
- Personal attacks or insults
- Trolling, derogatory remarks
- Publishing private information

## Enforcement
Report violations to:
**conduct@thecomputationalcore.dev**

Violators may face:
- Warnings
- Temporary or permanent bans

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
